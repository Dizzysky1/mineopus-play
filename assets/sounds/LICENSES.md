# MineOpus recorded sounds: sources and licences

Every file in this folder was cut, filtered, pitch-shifted, loudness-normalised and re-encoded from the recordings
below by `tools/sound-assets/build.py` (manifest in that file, source table in `tools/sound-assets/sources.json`).
All sources are released under **CC0 1.0 (public domain dedication)**, so the derived files are CC0 as well; the
credits are a courtesy. No Mojang / Minecraft audio is used.
